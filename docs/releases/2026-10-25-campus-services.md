# 2026-10-25 校园生活服务与接口文档

开放平台提供 27 条接口，新增伙伴课表/日程、洗衣、电费历史和证明开具流程。新增权限为 `companions:read`、`laundry:read`、`documents:read`、`documents:issue`；已有密钥不自动取得新权限。证明开具为唯一 POST，HTTP 202 返回任务标识；状态查询和本人有效 PDF 下载使用读取权限。

网关支持白名单路径参数，限流、额度及日志按模板路径聚合；原始请求方法、资源路径和 JSON 字节共同参与内部签名。校验 JSON、未知参数和方法后才消耗调用额度，不转发开发者密钥。PDF 原始响应最大 20 MiB，其他响应仍为 16 MiB。

默认每日额度调整为 1,500，每分钟 30；一次性迁移现有默认平台、继承默认的用户、对应默认应用及接口限制，保留显式自定义限制、已用额度和历史用量。课程通过率及班级成绩分布的冷却归零；重启不覆盖之后的管理员调整。历史迁移保留原来的数值，避免新默认值改写历史语义。

文档补齐 10 条新增接口的参数、字段、选项、示例、关联流程及 OpenAPI，补齐新版日程重复规则、自定义课程和电费历史结构。说明小程序与 API 共用北京时间首次活动标记，首次调用可能先返回缓存、响应后后台同步、失败保留旧数据和后续重试。

文档直接铺在完整页面，隐藏文档页的全局侧栏及外层框线；顶部保留入口，其他页全局侧栏不再放文档条目。文档内部目录复用全局导航的图标、字号、间距与选中样式；取消选中左侧色条，展开和折叠使用 SVG 图标。请求方法、路径参数、JSON 请求体和 HTTP 202 可在示例及在线调试中正确使用，密钥仅存在当前接口页面内存。

目录固定在视口内并独立滚动；正文标题与下载按钮同行。分组标题为 15px，选项 13px；标题无悬停/按下底色且不可选中文字，选项保留一致的圆角矩形，清除旧文字下边距以对齐图标。下载按钮先验证 JSON Content-Type 和 OpenAPI 结构，再生成 JSON 文件；HTML 或错误响应只显示错误，不保存为契约。`download=1` 响应提供 JSON 下载文件名。

验证：Go MySQL/Redis 集成测试、race 检查及 vet 通过；前端 27 项测试、类型检查、lint、格式检查与构建通过；Chrome 扩展已连接并实际操作本地合成数据预览，核对布局、导航和新增文档。

宿舍生活合并电费余额、历史与洗衣状态三项。删除开放版本的电费楼栋和洗衣校区/楼栋/点位/账号选择接口；洗衣仅使用小程序保存的本人绑定，不接受任何查询参数。未绑定返回 binding=null 和空设备列表，不请求学校洗衣服务。

增加 `/mcp` 无状态 Streamable HTTP 入口，固定官方 Go SDK v1.8.0。按当前权限与接口状态发布 24 项具名结构化工具和只读工作指南；不发布任意 URL/身份代理，不把文件 base64 填入模型上下文。每次数据调用直接执行同一个 REST 网关，重新验证密钥、学校身份、IP、权限、配额与并发，签名和日志保持一致。协议发现不消耗数据额度，另有每 IP 每分钟 120 次保护；工具结果带状态、请求编号、剩余额度和重试等待时间。证明开具额外要求 MCP confirm=true，标为非幂等写操作。接入指南最后一项说明配置、自定义请求头、缓存时间、错误处理、外部内容信任与 REST 文件下载；不提供 OAuth 自动登录。
