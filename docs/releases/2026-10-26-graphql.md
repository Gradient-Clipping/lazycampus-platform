# 2026-10-26 GraphQL

新增 `/graphql` POST JSON 入口，固定 `github.com/graphql-go/graphql v0.8.1`。从现有 REST 契约构造 23 项查询和 1 项 Mutation，提供类型化字段选择、变量、别名、片段和标准自省；动态字典和数字/文字混合成绩使用 JSON 标量。字段描述引用当前接口权限，维护和权限变更在每次数据调用重新核验，不授予已有密钥新权限。

GraphQL、MCP 抽取共用的原 REST 网关调用器，数据请求继续使用相同签名、归属验证、额度、并发和北京时间首次活动同步。每个顶层数据字段独立计算额度，包括别名；每次实际调用使用独立请求标识，日志只记录既有接口模板，不记录 GraphQL 正文、变量或响应。部分字段失败保留其他数据，错误提供 path 和 extensions（原 HTTP 状态、业务码、请求标识、重试秒数）。传输与参数错误使用 GraphQL 错误信封和相应 HTTP 状态；已执行操作返回 200，由 data/errors 表达结果。

证明开具仅通过 Mutation，要求 `documents:issue`、有效证明标识和显式 `confirm: true`；202 只表示创建任务，不自动重试。PDF、校历图片及通知附件仍使用 REST。

请求先验证应用密钥、学校身份和 IP。自省及 apiGuide 不扣数据额度；所有协议请求另受每 IP 每分钟 120 次限制。只接受单个 JSON 请求对象，不支持 GET、URL 查询参数、订阅或数组批处理。正文最多 32 KiB、结果最多 2 MiB；查询最多 10 个顶层字段、16 层深度、1,000 个展开选择项。验证前先限制片段展开和循环，避免无效或昂贵文档进入执行。执行总超时 90 秒，单接口继续沿用 85 秒。

接入指南新增 GraphQL，位于 MCP 上方，提供鉴权、查询与变量、操作目录、自省、错误、额度、数据时间和证明接口契约。网页不嵌入面向 AI 的工具选择、确认和重试指示；这些工作指示仅由 Query description 及 apiGuide 提供，MCP 指示保留。前端增加 GraphQL 语法高亮和英文文案。

验证涵盖真实 MySQL/Redis 集成、race/vet，Schema/文档示例静态校验、变量与字段选择、共享额度、部分失败、独立日志、即时维护/停用、绑定参数白名单、证明确认及正文传输、非法方法/来源/正文/批处理和深度/片段/根字段上限。前端保留 27 项测试，检查目录顺序和页面跳转。
